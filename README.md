# Умная теплица — IoT-панель на русском

Учебный веб-проект по лабораторной работе IoT Smart Greenhouse.

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в браузере. Для более стабильной работы рекомендуется запустить папку через VS Code Live Server.
3. Для графиков требуется подключение к интернету (Chart.js загружается через CDN).

## Реализовано
- Панель управления с KPI и графиком температуры.
- Три зоны выращивания: томаты, огурцы и зелень.
- Шесть типов датчиков и симуляция обновлений каждые 5 секунд.
- Режимы «Авто» и «Вручную», управление насосом, вентилятором, фитолампой, увлажнителем, обогревателем и форточкой.
- Защита насоса при низком уровне воды.
- Уведомления, журнал действий, оценка риска и рекомендации.
- Настройки порогов, localStorage, светлая/тёмная тема и адаптация под телефон.

## Важно
Это программный учебный симулятор. Он не подключён к настоящим датчикам или оборудованию. Пороговые значения демонстрационные.
